# Dear Diary — Минималистичный трекер тренировок

[![Android](https://img.shields.io/badge/Platform-Android-green?logo=android)](https://www.android.com/)
[![WebView](https://img.shields.io/badge/UI-HTML/CSS/JS-blue?logo=html5)](https://developer.mozilla.org/)
[![License](https://img.shields.io/badge/License-No%20License-red)]()

**Dear Diary** — это легкое Android-приложение для трекинга силовых тренировок, разработанное с упором на минимализм, скорость работы и полную автономность.

Приложение реализовано как нативная оболочка (WebView) вокруг локального веб-интерфейса, что обеспечивает плавную работу даже на старых устройствах и отсутствие зависимости от интернета.

## 📋 О проекте

Это инструмент для личного использования, адаптированный под специфические потребности в тренировочном процессе.

### Ключевые особенности:
- 🗓 **Система 3 дней**: Тренировки распределены на 3 дня. Пока не завершены все три дня, цикл не сбрасывается.
- 🏋️ **Универсальные упражнения**: Иконки и названия упражнений абстрактны (например, иконка бицепса может означать любое упражнение на бицепс). Это позволяет менять программу тренировок без необходимости редактировать код приложения.
- ⚡ **Быстрый ввод**: При выборе упражнения автоматически подставляются вес и количество повторений из предыдущей тренировки.
- ⏱ **Встроенные таймеры**: 
  - Общий таймер длительности тренировки.
  - Таймер отдыха (2 минуты) между подходами.
- 🌓 **Темы оформления**: 
  - Светлая тема для дневного использования.
  - **True Black** темная тема для экономии заряда на OLED-экранах.
- 📶 **Offline-first**: Работает полностью без интернета. Все данные хранятся локально на устройстве.

## 🛠 Технологии

Проект гибридный:
- **Android Native (Java/Kotlin)**: Оболочка приложения, управление WebView, доступ к файловой системе.
- **Web Stack (HTML5, CSS3, Vanilla JS)**: Вся логика интерфейса, расчеты и хранение данных (LocalStorage) реализованы в одном HTML-файле внутри assets.

## 🚀 Установка и запуск

### Вариант 1: Установка APK (Рекомендуется)

1. Скачайте файл `app.apk` из корня репозитория.
2. Разрешите установку из неизвестных источников в настройках вашего Android-устройства.
3. Запустите установочный файл.

### Вариант 2: Сборка из исходников

Если вы хотите изменить логику веб-части или нативную оболочку:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Q2369/dear-diary.git
   ```
2. Откройте проект в **Android Studio**.
3. Дождитесь синхронизации Gradle.
4. Нажмите **Run** (Shift + F10) для запуска на эмуляторе или подключенном устройстве.

> **Примечание**: Исходный код веб-интерфейса находится в папке `assets` (или `src/main/assets`). Вы можете редактировать `index.html`, `style.css` и `script.js` там.

## 📖 Как пользоваться

1. **Выбор дня**: На главном экране выберите день тренировки (День 1, 2 или 3).
2. **Выполнение упражнений**:
   - Нажмите на упражнение, чтобы начать подход.
   - Введите вес и количество повторений (предыдущие значения подставятся автоматически).
   - Нажмите "Завершить подход".
   - Запустится таймер отдыха на 2 минуты.
3. **Завершение**: После выполнения всех упражнений дня, день считается закрытым. Когда закрыты все 3 дня, цикл начинается заново.
4. **Настройки**: В меню можно сменить тему или полностью сбросить историю тренировок.
